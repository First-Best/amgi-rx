# 암기 처방전 복습 알림

책 「암기 처방전」(공부만했던의사 지음)의 복습 간격표대로 복습 날짜를 잡아 주는 휴대폰 앱이에요.

- 앱 주소: https://first-best.github.io/amgi-rx/
- 공부한 단원을 넣으면 시험까지 남은 날에 맞춰 1·2·3차 복습 날짜와 총복습 시작일을 잡아요.
- 복습 날에는 책을 펴기 전에 떠올려 쓰기, 질문 카드 한 바퀴, 펴서 맞춰 보기 순서로 안내해요.
- 기록은 쓰는 사람의 휴대폰 브라우저 안에만 저장돼요. 서버, 가입, 로그인, 광고, 방문 통계가 없어요.
- 홈 화면에 설치하면 인터넷이 없어도 열려요.

"처방전"은 비유예요. 이 앱은 공부법을 돕는 도구이고, 의학적인 처방이나 진료를 대신하지 않아요.

제목 글꼴은 Noto Serif KR의 일부 글자를 앱 안에 넣어 썼어요 (SIL Open Font License 1.1, `OFL.txt`).
